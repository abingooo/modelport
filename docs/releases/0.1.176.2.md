# ModelPort 0.1.176.2

> 本版本基于 Sub2API `v0.1.176`，将提示词审计整合为指令审核 V2 的补充链路，并保留 ModelPort 现有定价、计费和安全审核语义。

## 主要更新

- 提示词审计继承指令审核 V2 的分组范围和客户端规则，补充审核非 Responses 请求，并支持 `other`、`unknown` 客户端类型。
- Responses 请求继续只由指令审核处理，避免同一请求被两套审核链路重复审核。
- 审核节点改为通用 OpenAI-compatible 模型接口，支持千问、DeepSeek、豆包及自定义服务，可配置模型、超时、输入上限、输出 token 上限和响应格式。
- 节点探测会协商 `json_schema`、`json_object` 或文本 JSON 响应，并记录实际生效格式；多节点在超时或可故障转移错误时按顺序切换。
- 指令审核客户端可独立启用提示词审计补丁；内置内部客户端禁止启用，禁用的客户端不会触发补丁审核。

## 稳定性与安全

- 关闭提示词审计、关闭风控或禁用审核节点后，Worker 不再领取新任务，并在每次外部调用前重新检查开关；已经领取但尚未处理的任务会退回队列且不消耗重试次数。
- 关闭配置并清空 Token 时不再触发无凭据探测；旧模型契约的节点升级后默认禁用，必须由管理员重新配置并探测通过。
- 阻断模式下，指令审核范围快照不可用时返回 `503 prompt_guard_unavailable`；异步模式保持尽力而为，不阻塞业务请求。
- 审核任务和事件新增来源、指令审核配置版本、客户端规则、触发原因、模型契约版本和实际响应格式，便于追踪审核路由。
- 保留内部审核标记防伪校验，提示词审计与指令审核共用保护逻辑，外部请求不能伪装成内部审核流量。

## 数据库升级

- 新增 `224_prompt_audit_instruction_patch.sql`，为指令审核客户端增加提示词审计开关，并为提示词审计任务和事件补充路由元数据。
- 迁移会终止旧模型契约下仍在运行的提示词审计任务，并将旧节点标记为需要重新配置，避免旧提示词或响应契约继续运行。
- 不修改任何已发布 migration 的内容和 checksum；升级生产环境前必须备份 PostgreSQL。

## 验证与发布

- 后端安全审核、路由和迁移测试，Worker 竞态测试，以及前端单元测试、类型检查、Lint 和生产构建均已通过。
- 测试服务器已验证异步审核、同步放行与拦截、Responses 单链路审核、禁用 Worker，以及千问和 DeepSeek 等真实模型调用。
- 正式镜像：`ghcr.io/abingooo/modelport:custom-v0.1.176.2`，仅构建 `linux/amd64`。
- 发布流程只创建 GitHub Release 和 GHCR 镜像，不自动连接或更新生产服务器；生产环境仍由管理员在 ModelPort 站内手动更新。
