# ModelPort 0.1.176.2-dev.2

> 本版本是 `0.1.176.2` 的第二个开发候选，用于 CI 和发布验收，不代表生产环境已经部署。

## 相对 dev.1 的修复

- 清理仅在 `unit` 构建标签下出现的无效测试导入，使完整后端单元测试可正常编译。
- 为提示词审计出站契约测试补充安全的类型断言检查，满足 `golangci-lint` 的 `errcheck` 门禁。

## 候选内容

- 提示词审计继承指令审核 V2 的分组和客户端范围，补充非 Responses 请求，并支持 `other`、`unknown` 客户端。
- Responses 请求继续只由指令审核处理，避免重复审核。
- 审核节点支持千问、DeepSeek、豆包和自定义 OpenAI-compatible 服务，可配置模型、超时、输入上限、输出 token 上限与响应格式。
- 支持 `json_schema`、`json_object`、文本 JSON 响应协商和多节点故障转移，并记录实际生效格式。
- 关闭提示词审计、风控或节点后会阻止 Worker 继续领取任务和发起外部请求；暂停任务不消耗重试次数。
- 阻断模式下，指令审核范围不可用时安全地返回 `503 prompt_guard_unavailable`；异步模式保持尽力而为。

## 发布边界

- 开发镜像：`ghcr.io/abingooo/modelport:0.1.176.2-dev.2`，仅构建 `linux/amd64`。
- 正式版目标为 `custom-v0.1.176.2`；生产环境仍由管理员在 ModelPort 站内手动更新。
