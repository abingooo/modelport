# ModelPort 0.1.164.10-dev.1

本开发版本为用户侧 API 密钥增加端到端测试入口。镜像仅包含 `linux/amd64`，
不会自动部署到任何服务器。

## API 密钥测试

- 在用户“API 密钥”列表的每个具体 Key 操作区增加“测试”入口。
- 使用当前 Key 请求 `/v1/models`，只展示该 Key 所属分组实际可见的模型。
- 使用选定模型请求 `/v1/chat/completions`，实时展示流式思考内容和模型回复。
- 展示首字延迟与请求总耗时，支持停止请求和一键重新测试。
- 测试完成后刷新密钥用量，便于核对该次请求产生的实际消费。

## 链路与安全边界

- 测试请求直接经过现有下游网关，不增加可绕过鉴权、分组或计费的后台代测接口。
- 密钥状态、有效期、IP 访问控制、额度、限速、分组调度、倍率和计费规则均正常生效。
- 弹窗只显示脱敏 Key；完整 Key 仅作为网关请求的 `Authorization` 请求头发送。
- 无分组时显示明确空状态；停用、过期、额度不足和上游错误均展示网关真实错误。
- 关闭弹窗或重新测试会中止旧请求，旧请求不会覆盖后续弹窗状态。
- 当前入口验证 OpenAI 兼容的 Chat Completions 链路；图片、音频和视频应使用各自场景接口测试。

## 验证结果

- 新增组件与密钥列表 17 项定向测试通过。
- 前端 208 个 Vitest 文件、1434 项全量测试通过。
- TypeScript 类型检查、只读 ESLint 检查及前端生产构建通过。
- 流式分片、JSON 降级响应、首字延迟、网关错误、无分组及关闭取消场景均有覆盖。

