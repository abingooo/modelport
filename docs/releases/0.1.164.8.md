# ModelPort 0.1.164.8

本版本固定 ModelPort 免费分组、模型定价、模型广场和动态模型港首页里程碑。
发布镜像仅包含 `linux/amd64`，发布后只通知站点发现更新，不会自动部署服务器。

## 计费与定价

- 分组支持免费计费模式：保留真实上游成本与用量记录，但不扣减用户余额或订阅额度。
- API Key、分组选择器和分组管理统一显示“免费”，不再把免费分组错误显示为 `1x`。
- 管理员渠道定价支持按量、按次及图像规格等结构化价格，并可控制价格是否展示给用户。
- 用户模型定价只返回当前用户可访问分组及允许公开的模型价格，保留分组筛选和四类核心价格展示。
- API Key 列表支持跨页选择和批量修改分组，后端在单个事务中完成权限校验、更新及认证缓存清理。

## 模型服务

- 恢复用户模型广场和管理入口，复用现有渠道、分组与模型定价数据，支持平台、能力和场景筛选。
- 模型详情支持上下文、推荐状态、展示元数据以及 OpenAI、Anthropic、Google 调用示例。
- 独立生图站入口仅接受无凭据的绝对 HTTP(S) 地址；未配置或地址无效时显示安全空状态。
- ModelPort 小铺首期保持空页面，仅复用既有余额充值和兑换码入口，不创建或销售商品。
- 即时抽奖和定时开奖继续支持余额及订阅兑换码奖励，并保留库存、幂等、事务和审计约束。

## 模型港首页

- `/home` 使用程序化 Canvas 2D 绘制响应式港口，不再依赖照片背景。
- 双向货船、集成式岸桥、灯塔、模型货柜和昼夜环境共同表达统一模型网关；白天显示云层，夜间显示星空与真实月相。
- 首页只保留“模型定价”和“立即开始”两个业务入口，模型流仅展示实际模型厂商。
- ModelPort、模型港、浏览器标题、站点图标和中英文文案完成统一，同时保留自定义品牌与自定义首页兼容性。
- 支持深浅色、移动端、宽屏视觉缩放以及减少动画模式。

## 数据库兼容性

- `190_create_model_catalog_metadata.sql`：模型广场展示元数据及查询索引。
- `191_create_lottery_system.sql`：抽奖活动、奖品、参与记录、开奖记录及事务事件。
- `192_add_free_group_billing.sql`：分组免费计费标记。
- `193_add_channel_pricing_user_visibility.sql`：渠道模型价格的用户侧展示开关。
- 迁移均为增量变更，不删除现有用户、密钥、账号、渠道、计费或用量数据；旧版本可忽略新增表和字段。

## 验证结果

- 后端 Go 1.26.5 默认、`unit` 和 `integration` 三套全量测试通过。
- 前端 212 个 Vitest 文件、1460 项测试通过，TypeScript 类型检查和只读 ESLint 检查通过。
- 首页、Canvas、月相、平台颜色和页面标题的针对性测试通过。
- 正式发布前完成生产构建、AMD64 镜像构建及测试服务器健康和页面回环验证。

## 更新与回滚

```bash
docker pull ghcr.io/abingooo/modelport:custom-v0.1.164.8
```

管理员在测试站版本面板中刷新版本并人工确认更新。更新器只重建应用容器，保留
PostgreSQL、Redis 和应用数据卷。需要回滚时，将 `MODELPORT_IMAGE` 恢复为
`ghcr.io/abingooo/modelport:custom-v0.1.164.7` 并仅重建应用容器；不要删除数据库卷。
