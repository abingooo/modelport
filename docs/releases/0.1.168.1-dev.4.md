# ModelPort 0.1.168.1-dev.4

## 变更说明

- 在模型广场顶部“全部分组”筛选中增加“官方价格”虚拟分组，不再要求用户进入单张卡片查找。
- 选择“官方价格”后，全页仅展示具有官方按量参考价的模型，并统一切换卡片价格视图；切回实际分组后恢复正常价格。
- 模型卡片列数改为按容器宽度自动填充，宽屏、中屏和移动端自动选择合适列数，不再依赖固定列数断点。

## 兼容性

- “官方价格”仍为纯前端展示视图，不创建数据库分组，不参与 API Key 授权、模型路由或实际扣费。
- 本次不修改模型价格、分组倍率、渠道数据、用户余额和计费逻辑，也不新增数据库迁移。
- 这是开发预发布版本，仅用于测试服务器验证，不进入正式更新通道。

## 验证范围

- 顶部虚拟分组选项、全局与卡片价格状态同步、官方价模型过滤单元测试。
- 前端类型检查、ESLint 和生产构建。
- 测试服务器桌面及移动视口的自适应列数、官方价格全局切换和横向溢出回归。
