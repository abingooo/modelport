# ModelPort 0.1.164.6

本版本完成 ModelPort 模型港核心用户能力和运营能力建设。发布镜像仅包含
`linux/amd64`，发布后由管理员在网站版本面板中人工触发测试服务器更新。

## 主要功能

- API Key 列表支持跨分页选择，并在单个事务中批量修改分组；任意 Key 丢失、越权或并发删除时整批回滚，成功后清理认证缓存。
- 用户可见金额统一使用人民币符号 `￥`，数值保持 1:1，不修改内部 USD 计费字段和上游账单语义。
- 统一平台图标、主题色、分组标签和倍率标签；各服务商使用可辨识的中央颜色映射，“智谱 GLM”统一展示为“智谱AI”。
- 新增模型广场和管理入口，复用现有渠道、分组及模型定价，支持能力筛选、价格、上下文和 OpenAI、Anthropic、Google 调用示例。
- 新增可配置的独立生图站入口，前后端均校验外部 HTTP(S) URL，不配置时显示安全空状态。
- 新增 ModelPort 小铺空页面，复用已有余额充值和兑换码入口，首期不创建、不展示、不销售商品。
- 新增即时抽奖和定时开奖，支持余额与订阅兑换码奖励、资格分组、次数、概率和库存控制，并提供用户记录与管理端配置。
- 重构 `/home` 为响应式动态港口首页，包含船只、港口、灯塔、航线和数据流交互，并支持深浅色、移动端及减少动画模式。

## 数据库迁移

- `190_create_model_catalog_metadata.sql`：新增模型广场展示元数据表和查询索引；价格继续来自渠道配置。
- `191_create_lottery_system.sql`：新增活动、奖品、参与记录、开奖记录和事务事件表及约束索引。
- 两个迁移均为增量迁移，不修改或删除现有业务表和数据；已验证重复执行的幂等性。

## 风险与兼容性

- 首次启动新镜像时会自动执行迁移，启动时间可能比普通更新略长。
- 定时抽奖服务每 30 秒检查到期活动，开奖记录和事务锁保证多实例下不会重复派奖。
- 外部生图站 URL 为空时不会跳转；配置错误会被后端拒绝或从公开设置中隐藏。
- 生产构建仍有既有的 Vite 动态导入和大分块警告，不影响运行。

## 更新与回滚

```bash
docker pull ghcr.io/abingooo/modelport:custom-v0.1.164.6
```

发布本身不会自动更新服务器。管理员需要在 ModelPort 网站版本面板中刷新版本并人工确认更新，正常耗时约 2 到 5 分钟。

如果健康检查失败，宿主机更新服务会恢复更新前的镜像配置并重建旧容器。需要人工回滚时，将 `MODELPORT_IMAGE` 固定到上一个已验证的正式镜像并仅重建应用容器；PostgreSQL、Redis 和应用数据卷不得删除。新增表可以保留，不影响旧版运行，无需手工回滚数据库。
