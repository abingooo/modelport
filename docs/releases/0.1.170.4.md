# ModelPort 0.1.170.4

## 渠道监控

- 渠道监控新增 DeepSeek、通义千问、智谱AI、Kimi、ByteDance、MiniMax 和小米 MiMo，可独立配置模型、端点、请求模板及定时检测。
- 国内平台统一使用 OpenAI Chat Completions 兼容探测，并补齐平台图标、主题色、筛选项和中英文显示名称。
- 监控平台校验在前端、接口、服务和数据库约束层保持一致，已有 OpenAI、Anthropic、Gemini 与 Grok 监控不受影响。

## 充值阶梯赠送

- 管理员支付设置新增充值赠送开关和可排序阶梯；默认关闭，默认档位为 `<100 赠 3%`、`100-<500 赠 5%`、`500-<1000 赠 8%`、`>=1000 赠 10%`。
- 档位按用户实际支付的充值本金匹配，赠送金额按充值倍率换算后的基础到账余额计算；用户充值页实时展示基础到账、赠送余额和总到账。
- 订单保存本金、基础到账、赠送比例和赠送余额快照，确保后续调整规则不影响历史订单；首充邀请奖励仍按支付本金独立计算并可叠加。

## 数据与部署

- 新增 `197_channel_monitor_domestic_providers.sql`，仅扩展渠道监控和请求模板的平台枚举约束，不删除或改写现有记录。
- 充值赠送配置默认关闭，不新增订单字段，历史订单及用户、余额、API Key、订阅、用量、模型定价、邀请和抽奖数据保持不变。
- 开发候选版已在测试服务器完成双次迁移、容器健康、公网版本和核心数据一致性验收；迁移记录按预期从 `249` 增至 `250`。
- 正式镜像仅发布 `linux/amd64`，标签为 `ghcr.io/abingooo/modelport:custom-v0.1.170.4`。
- 发布工作流只创建 GitHub Release 和 GHCR 镜像，不自动更新生产服务器；正式镜像仍先部署至测试服务器人工验收。
