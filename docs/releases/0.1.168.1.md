# ModelPort 0.1.168.1

## 核心更新

- 基线升级至 Sub2API `v0.1.168`，纳入原生模型广场、Passkey、API Key 并发更新保护及上游网关修复。
- 模型广场采用 ModelPort 卡片式设计，支持动态平台导航、可访问分组筛选、官方参考价、按量/按次/图片规格价格和人民币展示。
- 同一模型的多个可访问分组合并展示，免费、专属、订阅、峰时倍率和最终实付价均由现有渠道定价与分组规则动态计算。
- 独立模型广场使用流体宽度和自适应列数，登录内嵌、未登录外部、宽屏与移动端保持各自合适的布局边界。

## 邀请奖励

- 将既有邀请奖励审核、余额发放、注册 IP 风控和首充奖励完整纳入 Go 源码及数据库事务管理，并停用旧外置触发器以防重复发放。
- 新增可配置的默认邀请人策略。注册未提供返利码时可自动绑定指定用户；显式返利码优先，已有关系和历史奖励数据不被覆盖。
- 有邀请历史的旧数据库自动保持用户 `1` 为默认邀请人；全新安装默认关闭，管理员可在邀请奖励规则中调整。

## 数据与部署

- 从 `0.1.166.2` 升级新增 Passkey、源码邀请奖励和默认邀请人三条迁移，既有 ModelPort 生产库目标迁移数为 `247`。
- 迁移不删除或重写用户、余额、API Key、订阅、用量、渠道定价及邀请历史；旧邀请触发器定义保留但禁用，便于受控回滚。
- 正式镜像仅发布 `linux/amd64`，镜像标签为 `ghcr.io/abingooo/modelport:custom-v0.1.168.1`。
- 发布工作流只创建 GitHub Release 和 GHCR 镜像，不自动部署测试服务器或生产服务器；上线仍需人工验收和触发更新。
