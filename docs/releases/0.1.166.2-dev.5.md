# ModelPort 0.1.166.2-dev.5

本开发版本将 TokensHub 邀请奖励机制重构为 ModelPort 原生源码能力，镜像仍只构建
`linux/amd64`。该版本属于开发通道，不向稳定版实例推送更新。

## 邀请奖励

- 新增注册奖励和首充奖励审核计划，保留原有按比例邀请返利，两套机制可以并行使用。
- 新增管理员审核工作台、风险指标、成组审核及余额和订阅奖励的幂等发放。
- 用户邀请页适配 ModelPort 蓝、青、金、红主题，展示奖励规则、审核进度和邀请状态。

## 数据兼容

- 原地接管 `referral.reward_reviews`、`referral.balance_grants` 和
  `referral.user_registration_ip_proxy`，不重算、不补发、不删除历史数据。
- 保留旧数据库触发器定义但迁移后禁用，避免新旧逻辑重复生成奖励。
- 固化历史审核发放边界，边界前待处理记录可查看和拒绝，但禁止误发。

## 验证

- TokensHub 生产只读快照迁移前后审计指纹一致，1928 条奖励审核、688 条余额发放和
  377 条注册 IP 记录完整保留。
- 本地 Docker 回环覆盖邀请绑定、风险评估、成组审核、订阅和余额发放及重复审核幂等性。
- 修复管理员作为邀请人时 PostgreSQL 风控查询的结果集生命周期和时间参数类型问题。
