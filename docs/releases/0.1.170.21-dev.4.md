# ModelPort 0.1.170.21-dev.4

## 可信哈希原文查看修复

- 可信哈希列表现在会读取内容保险库中的有效明文元数据，不再把已有加密原文的记录错误标记为 `unavailable`。
- 从明文创建或由审核流程写入保险库的可信哈希，可以在管理端正常点击“查看原文”并完成解密查看。
- 仅导入 SHA-256、从未保存原文的记录仍保持 `unavailable`；本次修复不会尝试反推或补造原文。

## 兼容性与部署

- API 结构和数据库结构均未变化，无需执行数据迁移。
- 镜像仅构建 `linux/amd64`，用于 `test.modelport.link` 验收，不自动更新生产服务器。
