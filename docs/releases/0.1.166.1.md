# ModelPort 0.1.166.1

本版本将 ModelPort 的 Sub2API 基线从 `v0.1.164` 同步到 `v0.1.166`，完整保留
ModelPort 品牌、国内 OpenAI 兼容平台、免费分组、用户模型定价和安全更新机制。
发布镜像仅包含 `linux/amd64`，发布后只通知站点发现更新，不会自动部署服务器。

## 上游同步

- 新增面板 API 限流，并支持分别控制认证用户、重查询接口和公开 IP 的请求频率。
- 接入 OpenAI Live 分组能力，记录请求 `session_id`，修复 WebSocket 多轮模型计费、模型映射统计和最终上游模型记录。
- 完善 Antigravity OpenAI 兼容转发、Codex Responses 与 Anthropic 协议互转。
- 修复系统设置局部更新覆盖未提交字段、Gemini 重试、Claude Code 缓存识别及多币种支付统计。
- 增加 Gemini 3.6 Flash 定价、思考档位别名及 Claude Opus 5 等上游兼容更新。

## ModelPort 功能

- API Key 页面新增单 Key 通路测试，可选择模型、协议和流式模式，并展示首字节与总耗时。
- 保留 DeepSeek、Qwen、智谱 AI、Kimi、Doubao、MiniMax 和 MiMo 等平台适配。
- 免费分组继续记录真实上游成本和用量，但不扣用户余额或订阅额度。
- 用户模型定价继续只展示当前用户可访问分组及管理员允许公开的模型价格。
- 生图站和 ModelPort 小铺已从前后端、路由和设置中移除，充值与订阅维持 Sub2API 原生流程。
- API Key 认证缓存升级到 `v18`，同时缓存 `is_free` 与 `allow_live`，旧缓存会自动失效重建。

## 数据库兼容性

- 上游与 ModelPort 的 `187` 至 `190` 同号迁移按不同文件名并存，迁移器可在 TokensHub 和既有 ModelPort 数据库上分别补齐缺失记录。
- 新增 `usage_logs.session_id`、OpenAI Live 分组控制及注册邮箱别名去重索引，并保留 ModelPort 的平台、免费分组和定价展示字段。
- `194_remove_image_site_setting.sql` 只清理已经下线的 `image_site_url` 设置，不删除用户、API Key、账号、分组、渠道、余额、订单、订阅或用量记录。
- TokensHub 首次迁移必须使用独立 PostgreSQL/Redis 的蓝绿恢复方案，不能直接让新镜像改写唯一的生产数据库。

## 验证结果

- Go 1.26.5 默认、`unit` 和 `integration` 测试通过，后端生产二进制构建通过。
- 前端 ESLint、TypeScript、210 个 Vitest 文件共 1462 项测试及 Vite 生产构建通过。
- `0.1.166.1-dev.1` AMD64 镜像已在测试服务器完成数据库迁移、登录、管理员接口、API Key 模型发现、账号直连和下游流式请求验证。
- TokensHub 生产快照迁移演练保持 107 张源表、88 个原序列及关键业务数据一致；正式镜像发布不等同于批准生产切换，生产迁移仍须按独立运行手册执行。

## 更新与回滚

```bash
docker pull ghcr.io/abingooo/modelport:custom-v0.1.166.1
```

既有 ModelPort 实例可由管理员在版本面板中刷新版本并人工确认更新。更新器只重建应用
容器，保留 PostgreSQL、Redis 和应用数据卷。首次从 TokensHub 切换时必须先创建完整备份
并保留旧栈；不要删除、覆盖或复用唯一的 TokensHub 数据卷进行首次迁移。
