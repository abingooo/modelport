# ModelPort 0.1.170.2

## 功能更新

- 定时开奖在参与人数不少于剩余奖品数时，先按配置概率正常抽取，再随机补发全部剩余奖品，确保启用奖品库存发完；人数不足时仍保持原概率规则。
- 首页两个模型广场入口按登录状态路由：访客进入公开广场，已登录用户进入站内嵌入视图。
- 用户菜单按实际工作流重新排序，自定义菜单紧跟渠道状态；自定义页面不再显示右上角“新窗口打开”按钮。
- 站内顶部“文档”更名为“使用文档”，使用文档与模型广场入口改为更醒目的 ModelPort 蓝色层级。

## 首页与主题

- 海面统一为 ModelPort 蓝，货船、立方体货柜、集成塔吊和港区结构增加立体光影，同时保留原有港口构图和双向船只动画。
- 移除首页底部两行横向移动的模型图标；模型徽章仍作为码头货柜保留。
- 补充中间宽度的连续港区位移，避免浏览器 200% 缩放时塔吊遮挡首页文案。
- 成功提示、系统设置保存反馈和订阅套餐销售强调色统一为 ModelPort 主题蓝。

## 生图功能边界

- 退役 ModelPort 内置批量生图产品及其前后端入口、任务队列、处理器和后台配置。
- 保留用户自定义菜单 `/image/`、OpenAI 标准 `/v1/images/*` 接口、历史数据表、Ent 结构及既有迁移校验兼容，不删除历史数据。
- 已退役的 `/v1/images/batches*` 路由返回 `404`，不影响标准图片生成接口。

## 数据与部署

- 本版本不新增数据库迁移，不修改用户、余额、API Key、订阅、用量、模型定价、邀请或抽奖历史数据。
- 开发候选版已在测试服务器完成自动更新、容器健康、桌面/移动端、深浅色和公网路由验收；升级前后核心业务表行数及 `249` 条迁移记录保持一致。
- 正式镜像仅发布 `linux/amd64`，标签为 `ghcr.io/abingooo/modelport:custom-v0.1.170.2`。
- 发布工作流只创建 GitHub Release 和 GHCR 镜像，不自动更新生产服务器；正式镜像仍先部署至测试服务器人工验收。
