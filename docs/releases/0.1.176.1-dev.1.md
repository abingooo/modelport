# ModelPort 0.1.176.1-dev.1

> 本版本为开发候选，基于 Sub2API `v0.1.176`，合并 Sub2API `v0.1.173` 之后至 `v0.1.176` 的正式更新，并保留 ModelPort 现有产品语义。开发候选不代表生产环境已部署。

## 上游更新

- 支持分组逐模型定价和分组长上下文阶梯开关，并将定价信息贯通分组 API、认证快照和网关计费。
- 支持 Grok 4.6、新订阅档位识别、X Search，以及 Realtime 仅在实际观察到音频后计费。
- 加强 OpenAI-compatible Grok 缺失 usage 防漏计费、上游响应模型计费准入、Responses/Chat/WS 兼容和故障转移。
- 定时备份增加多实例 leader 锁，并改进大文件分卷上传与恢复。
- 收敛 Codex OAuth 设备指纹，修复个人订阅到期、账号调度阈值、运营内存显示和 API Key 非法数值校验。
- 风控后端异常沿用上游 `v0.1.176` 最终的 fail-open 行为；cyber policy 日志按内容审核的分组和模型范围记录。
- Go 工具链升级至 `1.26.6`，修复安全扫描识别出的标准库漏洞。

## ModelPort 合并语义

- 模型广场官方价继续来自管理员配置的渠道定价；同模型存在多个渠道时按渠道创建时间、渠道 ID 选择最早项。
- 实际计费与分组展示遵循“分组逐模型价 > 渠道价 > 内置价”；存在渠道价时，分组只覆盖部分 token 字段，其余字段继续继承渠道价，不回退 LiteLLM。
- 分组价、分组倍率、峰时倍率、用户倍率和免费分组只影响对应分组的展示与实收，不改写模型广场官方价。
- 保留 ModelPort 图片、视频、搜索和 Voice 显式分组定价，以及渠道 `user_visible`、国内 provider 和 Composite 平台语义。
- 渠道创建、编辑和账号统计定价规则均支持视频计费 DTO，并对嵌套定价项执行后端参数校验；前端在提交前拒绝非有限值和负数价格，同时保留显式零价格。
- 账号统计的视频费用按分辨率档位每秒价优先、默认每秒价兜底，费用为“每秒价 × 完成视频数 × 归一化时长”；缺失时长按 8 秒，时长收敛到 1–15 秒，显式零价仍作为有效覆盖。
- Composite 请求的异步用量记录任务会保留已解析目标平台和强制平台上下文，确保后台账号统计与渠道定价按实际承载平台取价，避免跨平台误选渠道价。
- 保留首充奖励与日常充值阶梯福利互斥，重复支付回调不会补发或叠加奖励。

## 指令审核保留

- 保留字段复审因 AI 端点超时失败后的异步续跑，避免同字段再次同步审核。
- 保留分组范围的客户端类型多选、筛选后全选和批量删除审核日志。
- 保留可信哈希原文解密查看及来源账号快照。
- 保留 DashScope OpenAI-compatible 适配，包括 `qwen3.5-plus`、`qwen3.6-plus` 和 `qwen3.7-plus`。
- 合入 WebSocket turn 级审核去重；只复用同一 turn 的 `allow`，下一 turn 重新审核，`flag`、`unavailable` 和 `block` 不缓存。

## 数据库升级

- 已发布的 `221_modelport_channel_monitor_v2_defaults.sql` 和 `222_restore_modelport_non_grok_video_prices.sql` 内容保持不变。
- 上游分组逐模型定价迁移以 `223_group_model_pricing.sql` 接入，新增 `groups.long_context_pricing_enabled` 和 `groups.model_pricing`；存量分组的长上下文定价默认开启。
- 升级前必须备份 PostgreSQL，并在生产快照副本验证 migration checksum、存量分组默认值和重复启动。

## 发布边界

- 本候选仅用于代码审查、CI 和测试服务器验收，不连接生产服务器。
- 正式版通过 `custom-v0.1.176.1` 发布 `linux/amd64` GHCR 镜像；生产环境继续由管理员在 ModelPort 站内手动更新。
