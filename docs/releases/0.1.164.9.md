# ModelPort 0.1.164.9

本版本统一 ModelPort 的模型发现入口，收敛受支持平台，并完善账号添加页的平台徽章。
发布镜像仅包含 `linux/amd64`，发布后只通知站点发现更新，不会自动部署服务器。

## 模型定价

- 用户侧只保留“模型定价”，继续按当前用户可访问分组展示管理员允许公开的模型价格。
- 删除用户端和管理端模型广场页面、导航、路由、API、服务、仓库及运行时依赖，避免与模型定价形成重复入口。
- 模型广场历史数据库迁移继续保留，保证已升级实例与全新实例使用同一迁移链；运行时代码不再读取或写入相关表。

## 平台收敛

- 从账号、分组、渠道、配额、复合路由、调度、错误透传、模型建议和前端类型中移除 OpenRouter 与 SiliconFlow。
- 后端服务层拒绝为未知或已下线平台新建账号、分组、渠道定价及模型映射。
- 网关拒绝调度数据库中可能残留的已下线平台分组，同时保留旧数据供审计或人工迁移，不执行破坏性删除。
- 历史平台迁移保持不变，仅用于数据库迁移链兼容。

## 平台徽章

- 账号添加页第一行的 Anthropic、OpenAI、Gemini、Antigravity 和 Grok 徽章使用各自集中式主题色。
- 浅色和深色模式使用独立对比度，并复用全站平台配色来源，避免局部硬编码漂移。

## 数据库兼容性

- 本版本不新增数据库迁移，不删除账号、分组、渠道、密钥、用户、计费或用量数据。
- 已执行的 `188_add_openai_compatible_providers.sql` 与 `190_create_model_catalog_metadata.sql` 保持原样，避免破坏迁移校验和新实例初始化。
- 已下线平台的存量记录不再参与新配置或网关调度，可由管理员后续按实际数据情况人工归档。

## 验证结果

- 后端 Go 1.26.5 默认、`unit` 和 `integration` 三套全量测试通过，GitHub CI 与 `golangci-lint` 通过。
- 前端 207 个 Vitest 文件、1428 项测试通过，TypeScript、ESLint 和生产构建通过。
- 模型广场及两个下线平台的运行时代码静态扫描无残留，历史迁移与发布文档除外。
- `0.1.164.9-dev.1` AMD64 镜像已在测试服务器完成拉取、容器重建、版本、架构、API 404、公网健康及首页渲染验证。

## 更新与回滚

```bash
docker pull ghcr.io/abingooo/modelport:custom-v0.1.164.9
```

管理员在测试站版本面板中刷新版本并人工确认更新。更新器只重建应用容器，保留
PostgreSQL、Redis 和应用数据卷。需要回滚时，将 `MODELPORT_IMAGE` 恢复为
`ghcr.io/abingooo/modelport:custom-v0.1.164.8` 并仅重建应用容器；不要删除数据库卷。
