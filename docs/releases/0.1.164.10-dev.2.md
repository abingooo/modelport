# ModelPort 0.1.164.10-dev.2

本开发版本移除 ModelPort 曾新增的独立生图站与 ModelPort 小铺，恢复清晰的产品边界。
充值和订阅能力继续沿用 Sub2API 原生实现，镜像仅包含 `linux/amd64`。

## 产品入口清理

- 删除用户侧“生图站”和“ModelPort 小铺”页面、路由、侧栏入口及中英文文案。
- 删除管理员侧独立生图站 URL 配置，以及对应的前后端 API 字段和设置审计逻辑。
- 数据库迁移仅清理废弃的 `image_site_url` 设置，不修改其他业务数据。
- 通用自定义菜单保持不变，管理员仍可按现有机制配置外部站点入口。

## 原生充值与订阅

- 保留余额充值、订阅购买、我的订阅、兑换码、订单及其管理员功能。
- 保留 `purchase_subscription_enabled` 和 `purchase_subscription_url` 配置。
- 支付渠道、订单处理、余额入账、兑换码发放和订阅管理逻辑均未改动。

## 回归边界

- 路由与侧栏测试明确验证已删除入口不会重新出现。
- 路由与侧栏测试明确验证 `/purchase`、`/subscriptions`、`/redeem` 和 `/orders` 继续可用。
- 本版本只部署到 ModelPort 测试服务器，不连接或修改 TokensHub 生产服务器。

## 构建与部署

```bash
docker pull ghcr.io/abingooo/modelport:0.1.164.10-dev.2
```
