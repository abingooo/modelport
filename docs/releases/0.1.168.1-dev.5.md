# ModelPort 0.1.168.1-dev.5

## 变更说明

- 模型广场新增动态平台导航，展示平台图标和模型数量，并支持横向滚动，平台来源完全跟随当前可见模型。
- 重构计价方案筛选，将官方参考价、专属分组、订阅分组和按量分组分层展示，同时显示免费状态或有效倍率。
- 新增按模型名称、按输出价格降序排序，并记住平台、平台内分组和排序偏好。
- 保留 ModelPort 的卡片式四价格展示、平台主题色、自适应列数，以及按量、按次和图片计费表达。
- 优化移动端筛选展开、窄屏短文案与暗色模式，官方价格继续明确标注为不参与实际扣费的参考价。

## 设计与兼容性

- 借鉴 TokensHub 模型广场的平台计数、全局计价方案、分组分类和偏好记忆逻辑，不复制其旧品牌、单文件页面或独立 Python 服务。
- 平台和分组均由 ModelPort 现有 API 动态生成，不硬编码固定供应商，也不改变管理员渠道定价工作流。
- 本次仅调整模型广场前端展示与本地浏览偏好，不修改数据库、模型价格、用户余额、API Key 授权、路由或扣费逻辑。
- 这是开发预发布版本，仅用于测试服务器验证，不进入正式更新通道。

## 验证范围

- 模型聚合、官方参考价过滤、输出价格排序、动态平台计数、分组分类和筛选事件单元测试。
- 前端 ESLint、类型检查和生产构建。
- 桌面与真实 390px 移动视口下的浅色、暗色、筛选展开和分组菜单视觉回归。
