# ModelPort 0.1.170.13 指令审核需求证据矩阵

本文以 `v0.1.170.13` Goal 需求和当前工作树为准，记录需求、实现位置、自动化测试、测试服运行证据及残余风险。

## 证据状态

- **静态已定位**：当前工作树中存在对应实现或迁移；不等于运行结果已经通过。
- **自动化已通过**：对应测试已在当前候选源码上运行并通过。
- **测试服已验证**：已在 `test.modelport.link` 的隔离测试栈运行并核对事件或数据库结果。
- **部分证据**：只证明子路径，不能外推到完整 HTTP、SSE、WebSocket、浏览器或生产拓扑。
- **待验证**：当前没有足够的本轮运行证据，发布前必须执行并保存结果。

当前候选已通过 Go 全量测试、指令审核 race 定向测试、真实 PostgreSQL 集成与迁移测试、前端完整 Vitest、TypeScript、ESLint 和生产构建。`linux/amd64` 的 `0.1.170.13-dev.3` 已部署测试服；生产服务器未操作。
