# ModelPort 0.1.170.24-dev.1

## 指令审核范围与日志

- 分组审核范围支持同时选择多个客户端类型，并兼容“全部客户端”与指定客户端共存。
- 编辑分组范围时保留仍匹配的原范围记录，避免可信哈希授权失效；历史启用状态不一致时要求管理员明确确认。
- 审核日志支持在筛选结果中全选或取消全选当前页，并批量删除所选记录。
- 筛选、翻页和加载失败会清空旧选择，删除末页记录后自动返回仍有效的页码，避免误删旧结果。

## 可信哈希账号来源

- 可信哈希、风险哈希和异步复审任务记录请求账号 ID 与邮箱快照。
- 即使来源事件或账号后来被删除，管理端仍保留可审计的邮箱来源快照。
- 手工录入或仅导入摘要、没有请求来源的记录会明确显示为不适用。

## 阿里百炼兼容

- OpenAI 兼容地址可直接填写 `https://dashscope.aliyuncs.com/compatible-mode/v1`，不会再重复拼接 `/v1`。
- 指令审核 AI 节点覆盖 `qwen3.7-plus`、`qwen3.6-plus` 和 `qwen3.5-plus`。
- 完整 `models` 或 `chat/completions` 端点可在两类请求之间正确切换，同时保留普通代理目录的旧拼接语义。

## 可靠性与部署

- 失败复审重入、观察模式转强制模式及来源账号更新在同一事务提交，并统一审核任务锁顺序以避免并发死锁。
- 新增数据库迁移 `220_instruction_audit_v2_source_accounts.sql`，会为历史记录回填仍可关联的账号来源。
- 镜像仅构建 `linux/amd64`，用于测试服务器验收；发布流程不会自动更新测试或生产服务器。
