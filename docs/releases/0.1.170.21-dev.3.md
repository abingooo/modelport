# ModelPort 0.1.170.21-dev.3

## 指令审核复核任务修复

- 相同字段已有 `pending`、`retry` 或 `processing` 复核任务时，复用原任务和首次同步审核结论，不再重复调用同步 AI。
- 异步复核耗尽重试进入 `failed` 后，相同字段再次进入会原子恢复为 `retry`，保留已有有效票数并只重试未形成有效结论的端点。
- 观察模式任务切换到拦截模式时清空旧票并重新排队；首次事件缺失时拦截模式保持失败关闭。
- 审核日志新增“复用异步复核”和“失败任务重新排队”原因，并保留原复核任务关联。

## 同批稳定性修复

- 强化 AI JSON 返回契约和超时分类，使节点测试返回可操作的错误原因。
- 将 AI 槽位唯一约束冲突映射为明确的管理端冲突响应。
- 可信哈希接口固定返回数组类型，避免空作用域在前端触发运行时异常。

## 验证与部署

- 后端 `securityaudit` 普通测试与 race 测试通过。
- 前端指令审核定向测试和 TypeScript 类型检查通过。
- 镜像仅构建 `linux/amd64`，用于 `test.modelport.link` 验收，不自动更新生产服务器。
