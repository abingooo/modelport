# ModelPort 0.1.168.1-dev.2

## 变更说明

- 将模型广场重构为响应式卡片布局，按供应商分区展示；桌面端自动排列多列，移动端保持单列且不产生横向滚动。
- 同一模型存在多个可访问分组时合并为一张卡片，并支持在卡内切换分组，实时查看该分组对应的免费、专属、订阅、峰时和实际价格状态。
- 按量模型固定展示输入、输出、缓存写入、缓存读取四项价格，实际价格使用后端最终计算结果，LiteLLM 官方价格作为次级参考。
- 支持上下文阶梯价格展开，以及按次、按图片和 `1K`、`2K`、`4K` 等通用规格价格行。
- 渠道定价新增“展示到模型广场”开关。关闭后仅隐藏用户侧展示，不改变模型路由、白名单和实际计费。
- 完善免费分组、用户专属倍率、当前峰时倍率及图片独立倍率的展示价格计算，并统一管理员渠道定价页面的美元单位。

## 兼容性

- 本次不新增破坏性数据库迁移，复用上游 `v0.1.168` 已存在的 `channel_model_pricing.user_visible` 字段。
- 旧客户端未提交展示开关时默认保持展示，已有定价和用户数据不会被删除或重写。
- 这是开发预发布版本，仅用于测试服务器验证，不进入正式更新通道。

## 验证范围

- 前端类型检查、全量 ESLint 和生产构建通过。
- 模型广场卡片、供应商分区和多分组切换测试通过。
- 后端服务、公开模型广场和管理员渠道接口测试通过。
