# ModelPort 0.1.164.7

本版本撤回 ModelPort 0.1.164.6 中四项不再采用的产品功能，并恢复原有首页。
发布镜像仅包含 `linux/amd64`，测试服务器仍由管理员在网站版本面板中人工确认更新。

## 功能回退

- 删除用户端模型广场、管理端模型广场、模型目录 API、展示元数据服务及相关导航入口。
- 删除独立生图站页面、导航入口、公开配置字段和管理端地址配置。
- 删除 ModelPort 小铺页面及导航入口；原有充值、兑换码和订阅页面保持不变。
- 删除动态港口首页及 Canvas 场景，`/home` 恢复到引入港口首页之前的稳定版本。

## 保留功能

- API Key 跨页选择和事务化批量修改分组继续保留。
- 用户可见金额的人民币符号展示继续保留，内部计费字段不变。
- 平台中央主题色、图标和厂商命名优化继续保留。
- 即时抽奖、定时开奖及余额/订阅兑换码奖励继续保留。

## 数据库兼容性

- 本版本不新增数据库迁移，也不删除现有业务数据。
- `0.1.164.6` 已执行的模型广场迁移记录和表结构继续保留，以保证已升级实例和全新实例使用同一迁移历史；运行时代码不再读取或写入该表。
- 抽奖迁移和相关数据保持有效。

## 验证结果

- 后端 `go test ./...`、`go test -tags=unit ./...` 和 `go test -tags=integration ./...` 通过。
- `golangci-lint v2.9` 检查结果为 0 issues。
- 前端 199 个 Vitest 文件、1412 项测试通过，TypeScript 类型检查和 ESLint 通过。
- 前端生产构建通过；路由测试确认四个已撤回入口不再注册，抽奖路由仍正常注册。
- 首页文件和中英文首页文案已与港口首页改造前版本逐文件核对一致。

## 更新与回滚

```bash
docker pull ghcr.io/abingooo/modelport:custom-v0.1.164.7
```

管理员在网站版本面板中刷新版本并人工确认更新。更新器会保留 PostgreSQL、Redis 和应用数据卷，仅重建应用容器。

如需回滚，将 `MODELPORT_IMAGE` 恢复为 `ghcr.io/abingooo/modelport:custom-v0.1.164.6` 并仅重建应用容器；不要删除数据库卷。
