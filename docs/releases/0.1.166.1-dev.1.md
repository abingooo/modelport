# ModelPort 0.1.166.1-dev.1

本开发版本将 ModelPort 的官方基线从 Sub2API `v0.1.164` 同步到 `v0.1.166`，
完整保留现有 ModelPort 品牌、平台接入、免费分组、用户模型定价、下游密钥测试与安全更新机制。
发布镜像仅包含 `linux/amd64`，本版本只用于测试服务器验证。

## 上游同步

- 新增面板 API 限流，可分别控制认证用户、重查询接口和公开 IP 的每分钟请求量。
- 接入 OpenAI Live 分组能力，并保留 ModelPort 免费分组字段和计费语义。
- 记录请求 `session_id`，修复 WebSocket 多轮模型计费、模型映射统计和最终上游模型记录。
- 完善 Antigravity OpenAI 兼容转发、Codex Responses 与 Anthropic 协议互转。
- 修复系统设置局部更新覆盖未提交字段、Gemini 重试、Claude Code 缓存识别及多币种支付统计。
- 增加 Gemini 3.6 Flash 定价与思考档位别名处理。

## ModelPort 兼容

- API Key 认证缓存升级到 `v18`，同时缓存 `is_free` 与 `allow_live`，旧快照自动失效重建。
- 用量记录同时保留上游 `session_id` 和 ModelPort `billing_model`，各类单条与批量写入路径使用同一字段顺序。
- 上游与 ModelPort 的 `187-190` 同号迁移按不同文件名并存；现有 TokensHub 和 ModelPort 数据库均可增量应用缺失部分。
- 保留 DeepSeek、Qwen、智谱 AI、Kimi、Doubao、MiniMax 和 MiMo 等平台适配，不恢复已下线的平台入口。
- 保留免费分组不扣用户余额但记录实际成本的行为，以及用户可访问分组的模型定价页面。

## 部署边界

- 不连接或修改 TokensHub 生产服务器。
- 先在 ModelPort 测试服务器验证数据库迁移、登录、API Key、计费、价格展示、管理设置和前端页面。
- PostgreSQL、Redis 与应用数据卷保持原位，更新只替换 ModelPort 应用镜像。
