# ModelPort 0.1.173.2

## 充值福利修复

- 新用户首充奖励与日常充值阶梯赠送不再重复叠加。
- 余额充值仍在支付成功时即时发放匹配档位的阶梯赠送；首充邀请奖励进入审核时，会扣除该订单已经到账的阶梯赠送，只补足首充奖励差额。
- 例如首充 100 元、首充奖励比例为 10%、阶梯已赠送 5 元时，首充审核奖励为 5 元，用户该笔充值的总福利仍为 10 元，而不是 15 元。
- 当阶梯赠送已经达到或超过首充奖励时，不再创建好友额外余额奖励审核单；邀请人的固定首充奖励不受影响。
- 非首充订单、没有邀请关系的充值以及关闭首充奖励后的充值继续按原有阶梯规则处理。

## 兼容性与审计

- 互斥金额使用订单创建时持久化的阶梯赠送快照，并在订单中原子记录首充福利结算结果；后续调整阶梯或首充配置、重复回调均不会改写历史订单或补发奖励。
- 首充审核单记录名义奖励、阶梯抵扣和净奖励金额，便于后台追溯。
- 不修改已有首充审核单，不需要执行数据库迁移。

## 发布

- 正式镜像仅构建 `linux/amd64`，发布为 `ghcr.io/abingooo/modelport:custom-v0.1.173.2`。
- 发布流程只创建 GitHub Release 和 GHCR 镜像，不连接生产服务器；生产环境由管理员在 ModelPort 站内人工确认更新。
