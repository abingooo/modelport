# ModelPort 0.1.164.8-dev.7

本开发版本完成 ModelPort 0.1.164.8 正式发布前的首页与品牌收尾。镜像仅包含
`linux/amd64`，不会自动部署到任何服务器。

## 首页与品牌

- 使用程序化 Canvas 2D 港口替换照片背景，统一 ModelPort 与“模型港”的品牌表达。
- 港区包含双向货船、集成式岸桥、灯塔、模型货柜以及昼夜变化；白天显示动态云层，夜间显示星空和真实月相。
- 首页主导航和首屏只保留“模型定价”与“立即开始”两个业务入口，避免动画场景被次要操作遮挡。
- 底部模型流只展示实际模型厂商，移除 SiliconFlow 和 OpenRouter 等聚合平台，并为深色图标提供夜间反色与毛玻璃承载效果。
- 首页标题、浏览器标题、站点图标、中英文文案及默认品牌统一为 ModelPort；自定义品牌和自定义首页内容继续兼容。
- 支持深浅色、移动端、宽屏视觉缩放和 `prefers-reduced-motion` 简化动画模式。

## 验证结果

- 首页、Canvas、月相、平台颜色和页面标题共 37 项针对性测试通过。
- 前端 212 个 Vitest 文件、1460 项测试通过。
- TypeScript 类型检查和只读 ESLint 检查通过。
- 后端 Go 1.26.5 默认、`unit` 和 `integration` 三套全量测试通过。

## 构建与部署

```bash
docker pull ghcr.io/abingooo/modelport:0.1.164.8-dev.7
```

该版本用于发布流水线校验，不会连接生产服务器。正式测试部署使用
`custom-v0.1.164.8` 固定镜像。
