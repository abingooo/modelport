# ModelPort 0.1.170.6

## Codex 配置

- OpenAI 平台 API 密钥的 Codex 认证模式调整为左侧 API Key Mode、右侧兼容模式，位置与默认选择保持一致。
- API Key Mode 继续作为普通 Codex CLI 和 WebSocket 配置的默认值；兼容模式仍可手动选择。

## 邀请返利界面

- 管理员侧“邀请返利”改为单一主菜单项，直接进入奖励审核面板，不再展示奖励审核、邀请记录、返利记录和提取记录子菜单。
- 邀请记录、返利记录和提取记录的原有路由、接口及历史数据继续保留，仅从管理员侧栏移除入口。
- 用户侧邀请返利页面移除“持续充值返利”卡片、返利比例、可转返利额度和转入余额操作，保留邀请码、邀请链接、注册与首充奖励及奖励进度。
- 持续充值返利的后台字段、历史额度和记录不删除、不迁移，本版本仅调整用户可见界面。

## 验证与部署

- 三项相关测试 `29/29`、前端完整测试集 `223` 个测试文件及 `1565` 项测试全部通过。
- 已通过 Vue TypeScript 类型检查、相关 ESLint 检查和 Vite 生产构建；本版本不新增数据库迁移。
