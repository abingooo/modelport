# ModelPort 0.1.166.2

本版本用于把 TokensHub 核心业务安全切换到 ModelPort。推荐、抽奖、旧模型广场、首字超时
控制页和自定义风控代理等 TokensHub 周边功能保留数据但暂不上线，后续逐项原生适配。

## 生产迁移护栏

- 新增只连接 PostgreSQL 的 `--migrate-only`，迁移完成即退出，不启动 Redis、HTTP 服务或
  后台 worker。
- 提供 PostgreSQL 数据、财务、序列、约束、索引、函数和触发器审计，以及 244 条目标迁移
  的硬断言。
- 提供 Redis 登录会话审计与裁剪脚本，覆盖前缀、类型、JSON、绑定状态、TTL 和内容指纹。
- 提供可逆的 TokensHub 周边触发器隔离和首次启动外发围栏，核心支付与通知可单独恢复。

## 兼容与验证

- 基于 TokensHub 快照完成 `236 -> 244` 迁移并验证重复执行幂等，1494 个用户、1469 个
  API Key、575 条订阅和 1,077,234 条用量完整保留。
- 9243 个登录会话键在裁剪、AOF 开启、Redis 重启和 ModelPort 隔离启动后保持内容指纹一致。
- 用户注册、密码登录、Refresh Token 轮换和用户 API Key 创建验证通过。
- OpenAI Chat 流式、含 `prompt_cache_key` 的 Responses、Anthropic Messages 和 Google 原生
  协议均已打通；付费与免费分组核算符合预期。
- TokensHub 原始 JWT/TOTP 密钥可读取全部 8 个渠道监控和 2 个支付实例，备份 S3 当前未配置。

## 部署要求

- 仅发布 `linux/amd64` 镜像，并使用正式标签和固定 digest。
- 首次生产切换必须执行 `docs/MODELPORT_PRODUCTION_CUTOVER_CN.md` 的蓝绿流程；禁止在旧库
  原卷上迁移，也禁止旧 TokensHub 与 ModelPort worker 同时写同一数据库。
- 切流前必须继承原 `JWT_SECRET` 和 `TOTP_ENCRYPTION_KEY`，关闭 Token 自动刷新，确认 Nginx
  可信代理、Redis 会话指纹、核心数据不变量、备份和回滚点。
