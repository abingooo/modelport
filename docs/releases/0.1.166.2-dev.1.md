# ModelPort 0.1.166.2-dev.1

本开发版本为 TokensHub 首次切换 ModelPort 增加生产迁移护栏，不改变正常网关请求、计费或
前端功能。镜像仅构建 `linux/amd64`，只用于测试服务器完成生产级迁移和回滚演练。

## 生产迁移能力

- 新增 `/app/sub2api --migrate-only`，只连接 PostgreSQL、应用内置迁移后立即退出，不连接
  Redis、不创建管理员或密钥、不写 setup 文件，也不初始化应用和后台 worker。
- CLI 版本信息与首次安装提示统一显示 `ModelPort`，二进制路径保持兼容。
- 增加迁移前后 PostgreSQL 归一化审计，覆盖既有表数据、序列、财务汇总、列、约束、索引、
  函数和触发器。
- 增加 244 条目标迁移硬断言和 TokensHub 周边触发器隔离脚本。
- 增加 Redis 登录会话保留、缓存裁剪和重启后审计脚本。
- 增加可逆的首次启动外发围栏，核心支付和通知可在验收后单独恢复。

## 演练结果

- 从原始 TokensHub dump 全新恢复后完成 `236 -> 244` 迁移，重复执行保持幂等。
- 1494 个用户、1469 个 API Key、575 条订阅和 1,077,234 条用量均保留。
- 迁移前后 107 张既有表和 88 个序列的规范化审计文件 SHA-256 完全一致。
- Redis 保留 9243 个登录会话键，删除 3398 个旧缓存；开启 AOF 并重启后会话指纹不变。

## 部署边界

- 不连接或修改 TokensHub 生产服务器。
- 先部署 ModelPort 测试服务器，完成协议、计费、登录会话、后台隔离和人工更新回归。
- 生产首次切换必须遵循 `docs/MODELPORT_PRODUCTION_CUTOVER_CN.md` 的蓝绿流程。
