# ModelPort 0.1.170.3-dev.1

## 账号管理修复

- 修复 DeepSeek、通义千问、智谱AI、Kimi、ByteDance、MiniMax 和小米 MiMo 账号创建统一返回 `400` 的问题。
- 创建、编辑、批量编辑和账号列表统一按照后端支持范围展示上游计费探测功能，国内平台不再提交不兼容的探测参数。
- 后端兼容旧页面缓存：不支持探测的 API Key 平台即使误传默认探测开关，也可正常创建账号且不会启用探测；OAuth 等非法账号类型仍保持严格校验。

## 数据与发布

- 本版本不新增数据库迁移，不修改已有账号、用户、余额、API Key、订阅、用量、模型定价、邀请或抽奖数据。
- 开发镜像仅构建 `linux/amd64`，标签为 `ghcr.io/abingooo/modelport:0.1.170.3-dev.1`。
- GitHub Actions 只发布开发镜像和 prerelease，不自动更新测试服务器或生产服务器。
