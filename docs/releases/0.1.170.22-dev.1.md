# ModelPort 0.1.170.22-dev.1

## 客户端规则禁用能力

- 所有客户端识别规则均可切换为禁用，包括系统兜底规则 `other`、`unknown` 和可信内部规则 `modelport_internal`。
- `modelport_internal` 仅开放启用状态，规则标识、名称、说明、优先级和匹配配置继续保持锁定。
- 禁用客户端规则后，绑定该规则的专属审核范围不再生效；“全部客户端”审核范围仍按原有语义覆盖请求。

## 兼容性与部署

- 指令审核统计口径保持不变。
- API 和数据库结构均未变化，无需执行数据迁移。
- 镜像仅构建 `linux/amd64`；发布流程不会自动更新测试或生产服务器。
