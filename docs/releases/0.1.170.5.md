# ModelPort 0.1.170.5

## Codex 配置

- OpenAI 平台 API 密钥的“使用密钥”弹窗默认选择 API Key Mode，普通 Codex CLI 与 WebSocket 配置保持一致。
- 重新打开弹窗或切换平台后会恢复 API Key Mode 默认值；兼容模式继续保留，可供旧版客户端手动选择。
- 本次调整仅改变前端生成的 Codex 配置，不修改已创建的 API 密钥、分组、模型定价或网关认证逻辑。

## 邀请返利

- 管理员侧菜单继续显示“邀请返利”，点击父菜单会直接进入奖励审核面板，同时保留邀请记录、返利记录和提取记录入口。
- 修复邀请返利父菜单此前只展开但不导航的问题；侧栏折叠时点击该入口也能稳定打开奖励审核面板。
- 奖励审核、邀请关系、返利、提取及历史奖励数据不做迁移或改写。

## 验证与部署

- 前端完整测试集 `223` 个测试文件、`1565` 项测试全部通过，并通过 Vue TypeScript 类型检查与相关 ESLint 检查。
- 本版本不新增数据库迁移，不影响用户、余额、API Key、订阅、用量、邀请返利、模型定价或抽奖数据。
- 正式镜像仅发布 `linux/amd64`，标签为 `ghcr.io/abingooo/modelport:custom-v0.1.170.5`。
- 发布工作流只创建 GitHub Release 和 GHCR 镜像，不自动更新测试服务器或生产服务器，网站版本面板仅提示管理员人工更新。
