# ModelPort 0.1.164.9-dev.1

本开发版本收敛 ModelPort 的模型发现入口与受支持平台范围。镜像仅包含
`linux/amd64`，不会自动部署到任何服务器。

## 产品入口

- 用户侧只保留“模型定价”，继续按当前用户可访问分组展示公开价格。
- 删除用户端和管理端模型广场页面、导航、路由、API、服务及运行时依赖。
- 保留模型广场历史数据库迁移，保证已升级实例与全新实例使用同一迁移链；运行时代码不再读取或写入相关表。

## 平台收敛

- 从账号、分组、渠道、配额、复合路由、调度、错误透传、模型建议和前端类型中移除 OpenRouter 与 SiliconFlow。
- 服务层拒绝为未知或已下线平台新建账号、分组、渠道定价及模型映射。
- 网关拒绝调度数据库中可能残留的已下线平台分组，同时保留旧数据供审计或人工迁移，不执行破坏性删除。
- 历史平台迁移保持不变，仅用于数据库迁移链兼容。

## 平台徽章

- 账号添加页第一行的 Anthropic、OpenAI、Gemini、Antigravity 和 Grok 徽章使用各自集中式主题色。
- 浅色和深色模式使用独立对比度，并复用全站平台配色来源，避免局部硬编码漂移。

## 验证结果

- 前端 207 个 Vitest 文件、1428 项测试通过。
- TypeScript 类型检查、只读 ESLint 检查及前端生产构建通过。
- 后端 Go 1.26.5 默认、`unit` 和 `integration` 三套全量测试通过。
- 模型广场及两个下线平台的运行时代码静态扫描无残留，历史迁移与发布文档除外。

## 构建与部署

```bash
docker pull ghcr.io/abingooo/modelport:0.1.164.9-dev.1
```

该版本仅用于开发流水线和测试服务器验证，不连接或修改 TokensHub 生产服务器。
