# ModelPort 0.1.170.1

## 核心更新

- 基线升级至 Sub2API `v0.1.170`，完整保留 ModelPort 的动态港口首页、卡片式模型广场、免费分组、平台主题、邀请奖励和默认邀请人机制。
- 新增分组级利润控制，可按账号成本倍率、分组实付倍率、最低利润率和安全缓冲过滤调度候选，并在取得账号槽位后再次校验，避免高成本账号造成倒挂。
- 上游计费倍率探测扩展至 OpenAI、Anthropic、Gemini、Grok 和 Antigravity API Key 账号；可按账号启用倍率自动同步，并保留探测快照和写回日志。
- 管理端账号列表支持按当前筛选结果全选，批量删除增加并发限制；首页新增可选精简模式。

## 稳定性修复

- 修复 Anthropic 流式响应中断时部分用量丢失导致漏计费的问题。
- 修复 OpenAI WebSocket、流内限流、容量重试、Codex 工具与 instructions、加密上下文恢复等网关兼容问题。
- 修复 Responses 工具输出图片桥接、Grok 计费事件过滤、订阅配额窗口、支付设置保存、图片 data URL 分流和 SMTP 测试一致性问题。
- ModelPort 认证快照升级至 `v19`，同时覆盖免费计费、Live 能力与利润控制字段，升级后自动淘汰旧缓存。

## 数据与部署

- 新增 `192_group_profit_control.sql` 与 `193_group_profit_control_auth_cache_invalidation.sql` 两条幂等迁移，不删除或重写用户、余额、API Key、订阅、用量、渠道定价和邀请历史。
- 分组利润控制与账号倍率自动同步均默认关闭；未主动开启时，调度及计费行为与升级前保持一致。
- 正式镜像仅发布 `linux/amd64`，镜像标签为 `ghcr.io/abingooo/modelport:custom-v0.1.170.1`。
- 发布工作流只创建 GitHub Release 和 GHCR 镜像，不自动更新生产服务器；本版本先部署至测试服务器人工验收。
