# ModelPort 0.1.170.21

## 指令审核复核任务修复

- 相同字段已有 `pending`、`retry` 或 `processing` 复核任务时，复用原任务和首次同步审核结论，不再重复调用同步 AI。
- 异步复核因端点超时等原因耗尽重试并进入 `failed` 后，相同字段再次进入会原子恢复为 `retry`，保留已有有效票数并只重试尚未形成有效结论的端点。
- 观察模式任务切换到拦截模式时清空旧票并重新排队；首次事件缺失时拦截模式保持失败关闭。
- 审核日志新增“复用异步复核”和“失败任务重新排队”原因，并保留原复核任务关联。

## 可信哈希原文查看修复

- 可信哈希列表读取内容保险库中的有效明文元数据，不再把已有加密原文的记录错误标记为 `unavailable`。
- 从明文创建或由审核流程写入保险库的可信哈希，可以在管理端正常点击“查看原文”并完成解密查看。
- 仅导入 SHA-256、从未保存原文的记录仍保持 `unavailable`；哈希摘要无法反推出原文。

## 稳定性与兼容性

- 强化 AI JSON 返回契约和超时分类，使节点测试返回可操作的错误原因。
- 将 AI 槽位唯一约束冲突映射为明确的管理端冲突响应。
- 可信哈希接口固定返回数组类型，避免空作用域在前端触发运行时异常。
- API 结构和数据库结构均未变化，无需执行数据迁移。

## 验证与发布

- 后端 `securityaudit` 普通测试与 race 测试通过。
- 前端指令审核测试、TypeScript 类型检查和相关 ESLint 检查通过。
- 正式镜像仅构建 `linux/amd64`，发布为 `ghcr.io/abingooo/modelport:custom-v0.1.170.21`；发布流程不会自动更新测试或生产服务器。
