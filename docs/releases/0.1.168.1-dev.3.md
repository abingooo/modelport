# ModelPort 0.1.168.1-dev.3

## 变更说明

- 模型广场在桌面端调整为每行四张卡片，中等屏幕保持双列，移动端保持单列。
- 模型广场的实付价、官方参考价、按次价、按图片价及阶梯价格统一使用人民币符号 `￥`。
- 页面币种标识由 `USD` 调整为 `CNY`，价格数值按站内 1:1 余额规则原样展示，不进行汇率换算。
- 重构卡片内的价格分组信息，将免费、倍率、专属、订阅和峰时状态与当前分组集中展示，并增加可切换的“官方价格”虚拟分组。

## 兼容性

- 本次仅调整模型广场布局和价格展示，不修改模型基础价格、分组倍率、用户余额或实际计费逻辑。
- 不新增数据库迁移，不删除或重写已有渠道、分组、模型和用户数据。
- 这是开发预发布版本，仅用于测试服务器验证，不进入正式更新通道。

## 验证范围

- 前端模型广场卡片测试、类型检查、ESLint 和生产构建。
- 后端模型广场相关单元测试与服务构建。
- 测试服务器桌面端四列、移动端单列、深浅色和人民币价格显示回归。
