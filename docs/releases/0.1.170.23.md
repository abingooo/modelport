# ModelPort 0.1.170.23

## 模型广场渠道官方价

- 模型广场的“官方价格”改为读取渠道中配置的原始价格，不再读取 LiteLLM 参考价。
- 具体分组继续展示渠道原价应用分组倍率、峰时倍率和用户专属倍率后的价格。
- Token、分层、图片和按次计价均支持在分组价格与渠道官方价之间切换。
- 同一分组出现同名模型的异常配置时，优先使用创建时间最早的渠道；时间相同则按渠道 ID 选择。
- 仅展示明确配置价格且允许用户查看的渠道模型，模型广场不再使用 LiteLLM 价格兜底。

## 兼容性与验证

- LiteLLM 在计费、利润控制和“可用渠道”等其他模块中的现有逻辑保持不变。
- 模型广场 API 保留旧版 `official_pricing` 字段，由渠道原始 Token 定价生成，兼容旧客户端。
- API 和数据库结构均未变化，无需执行数据迁移。
- 后端完整 unit 测试与模型广场针对性 race 测试通过。
- 前端模型广场测试、TypeScript 类型检查、相关 ESLint 和生产构建通过。
- 正式镜像仅构建 `linux/amd64`，发布流程不会自动更新测试或生产服务器。
