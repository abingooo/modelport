# ModelPort 0.1.168.1-dev.1

## Changes

- Merges the upstream Sub2API `v0.1.168` baseline, including the native Model Plaza, Passkey support, API key lost-update protection, and upstream gateway fixes.
- Removes ModelPort's earlier user-facing Model Pricing implementation and restores the upstream Available Channels flow before adopting the native Model Plaza.
- Adapts the native Model Plaza to ModelPort free groups so free access is shown consistently without changing upstream cost references.
- Extends production migration verification for the new Passkey schema while preserving all existing ModelPort and TokensHub data checks.

## Deployment

- This is a development source version and is not a stable update notification.
- The upstream Passkey migration only adds new tables and does not rewrite existing users, API keys, balances, subscriptions, usage, or pricing data.
