# ModelPort 0.1.166.2-dev.3

本开发版本完成 TokensHub 首次切换前的会话、密钥和运行配置收口，镜像仍只构建
`linux/amd64`。

## 生产验收增强

- Redis 认证审计增加三个键前缀、预期类型、refresh token JSON、会话绑定和 TTL 分桶统计，
  可识别 RDB 未传输、TTL 被重置和键类型错误。
- 隔离启动验证 ModelPort 不会批量删除 TokensHub 的 9243 个认证键；此前测试站的 63 个键
  来自独立 Redis，并非迁移后丢失。
- 明确公网测试站使用独立 JWT/TOTP 密钥，生产原密钥只在隔离快照副本验收。
- 补充可信 Nginx 代理、Compose v1/v2、自动 Token 刷新、CORS、URL allowlist 和启动后
  时效状态变化的生产检查。

## 验收结果

- 测试服 PostgreSQL、Redis、应用同时重建后，认证键总数和值指纹完全一致。
- TokensHub 原始 JWT/TOTP 密钥启动无 mismatch；8 个渠道监控和 2 个支付实例全部可解密。
- 测试服已显式关闭上游 OAuth 自动刷新，并只信任宿主 Nginx 的 Docker 网关。
