# ModelPort 0.1.170.12

## 指令审核规则例外

- 规则集新增“两个审核字段均为空时放行”开关。仅接受 `instructions` 缺失或精确空字符串，以及 `input[1]` 缺失或结构合法的空文本；`null`、空格、错误类型、异常内容和非法 JSON 不会借此放行。
- 规则集新增用户放行白名单，可按邮箱搜索并多选用户，配置按稳定用户 ID 保存。命中分组和客户端审核范围后，白名单用户跳过指令正文校验。
- 多个规则集继续采用并集语义：任一启用规则集的有效哈希、空字段规则或用户白名单命中即可放行。只有例外配置、没有哈希的规则集也可作为有效规则，总开关和分组状态会正确识别。

## 审核处置与追踪

- 审核日志改为自适应布局，宽屏使用固定表格，较窄窗口使用信息卡片，不再依赖横向滚动；页面移除额外左右留白，事件、主体、客户端、校验结果和通知状态可直接查看。
- 每条拦截记录明确展示事件编号，并可与运维系统日志双向关联；被拦截事件以警告级别写入运维日志，便于按事件编号或请求 ID 定位。
- 审核日志支持单条删除、当前页批量删除以及带时间范围和筛选快照的批量清理。清理会同步删除关联加密证据和通知记录，并通过预览确认避免误删新记录。
- 审核日志新增“一键加入规则集”，管理员完成人工复核后，可将 `instructions`、`input[1]` 的摘要原子创建、重新启用并关联到指定规则集。

## 规则资源管理

- 哈希库支持删除未被引用的哈希；规则集支持删除未绑定审核范围的规则。仍有引用时返回明确冲突提示，避免误删正在生效的配置。
- 规则卡直接展示空字段放行状态和白名单人数；编辑弹窗增加严格语义说明、用户搜索多选和已有用户邮箱回显。
- 新增迁移 `203_instruction_audit_rule_exceptions.sql`，只增加规则集空字段开关和规则集用户白名单关系表，不修改已有用户、API Key、分组、哈希、审核日志或计费数据。
