# ModelPort 0.1.168.1-dev.7

## 变更说明

- 将生产环境既有的“无返利码注册默认绑定管理员”行为重构为源码管理的可配置策略，不再依赖硬编码补丁或数据库触发器。
- 邮箱注册与 OAuth 注册统一使用同一绑定路径；显式返利码始终优先，已有邀请关系保持不变，默认邀请人不能绑定自己。
- 默认绑定与注册 IP 采集、注册奖励审核单在同一事务中完成，失败继续按注册流程的既有规则降级，不阻断用户注册。
- 管理员可在邀请奖励规则中启用默认邀请人并配置用户 ID；后端同时校验 ID 格式和目标用户有效性。

## 数据兼容

- 新增 `196_affiliate_default_inviter.sql`。已有邀请历史的数据库自动启用用户 `1` 作为默认邀请人，保持生产行为；全新安装默认关闭。
- 迁移只补充邀请奖励 JSON 配置，不修改用户、余额、API Key、订阅、用量、邀请关系或历史奖励记录。
- ModelPort 生产迁移目标由 246 条提升到 247 条，重复执行迁移不产生额外业务数据。

## 发布边界

- 这是正式版前的最后开发构建，仅发布 `linux/amd64`。
- 推送开发版本和正式标签均不会自动连接或更新测试服务器、生产服务器。
