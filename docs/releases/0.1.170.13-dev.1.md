# ModelPort 0.1.170.13-dev.1

## 指令审核策略与结果

- 指令审核统一记录最终拦截、策略放行、AI 放行、哈希放行和例外放行，并提供独立统计与多条件筛选。
- 管理员可逐原因配置拦截、记录后放行、AI 二审和通知；所有策略放行均要求 TOTP 与明确二次确认，配置不可用和 AI 异常保持强制拦截。
- 被拦截请求通知用户和运维，策略放行只通知运维；通知异步去重、限流，且不包含字段原文或认证信息。

## AI、原文与翻译

- 可按 `instructions`、`input[1]` 顺序执行 AI 二审；通过后只在当前下游分组和客户端范围创建 24 小时临时哈希。
- 哈希与审核事件支持加密保存对应原文，敏感查看、复制、翻译及状态操作要求 TOTP，并写入独立访问审计。
- 管理员可按需分段翻译字段；凭据先脱敏，译文只在加密 Redis 中短期保存，并支持暂时故障重试。

## 大请求与可靠统计

- 默认审核请求体上限提高到 64 MiB，支持 1-128 MiB 配置、解析超时、严格 JSON 校验和并发内存预算，HTTP 与 WebSocket 共用相同规则。
- 正常放行事件可靠落库后再按保留期归档；小时聚合数组按事件编号分片，每行最多 4096 个时间戳，同时保持任意时间范围统计准确。
- 新增迁移 `204` 至 `210`，保留既有事件、规则、哈希、证据、通知、用户、API Key、余额、订阅和用量数据。

## 测试范围

- 已通过 Go 全量测试、真实 PostgreSQL 迁移与幂等测试、指令审核 race 测试、Go vet、1592 项前端测试、TypeScript、ESLint 和生产构建。
