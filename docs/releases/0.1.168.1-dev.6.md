# ModelPort 0.1.168.1-dev.6

## 变更说明

- 外部独立模型广场的导航和内容容器由固定 1280px 扩展为流体宽度，最高 2048px，改善 2K 与超宽屏空间利用率。
- 外部模型网格根据容器宽度自动增减列数；平台具有 4 个及以上模型时充分填充整行，1 至 3 个模型时限制卡片宽度，避免单卡被过度拉伸。
- 普通桌面与移动端继续自动回落为合适列数，不产生横向滚动或文字遮挡。

## 布局边界

- 本次仅修改外部独立页面 `/model-plaza`。
- 登录后的后台内嵌页面 `/model-plaza?embedded=1` 继续使用 `AppLayout` 和原有紧凑网格，不受外部宽屏规则影响。
- 未登录访问 `?embedded=1` 时仍按既有安全逻辑降级为外部独立页面。
- 本次不修改模型数据、渠道定价、分组、数据库、用户余额、路由或实际扣费逻辑。

## 验证范围

- 外部、登录内嵌和未登录降级三种布局分支单元测试。
- 模型广场相关 5 个测试文件共 18 项测试、ESLint、类型检查和生产构建。
- 2880px 超宽屏、1440px 桌面和真实 390px 移动视口视觉回归。
