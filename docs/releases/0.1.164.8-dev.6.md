# ModelPort 0.1.164.8-dev.6

本开发里程碑原生恢复并完善 ModelPort 模型港产品能力。镜像仅包含
`linux/amd64`，推送后不会自动更新测试服务器，仍由管理员在网站版本面板中人工确认。

## 主要功能

- API Key 列表支持跨页选择和批量修改分组，限制单次 500 个 Key；后端校验所有权、删除状态和分组权限，在单个事务中更新并清理认证缓存，接口支持幂等请求。
- 用户可见金额继续统一显示为 `￥` 且按 1:1 展示；平台图标、分组、倍率和订阅标签使用中央主题色，免费分组保持“免费”语义。
- 恢复用户模型广场和管理入口，价格来自现有渠道、分组和模型定价；支持搜索、能力与平台筛选、上下文、场景、推荐、可见性及 OpenAI、Anthropic、Google 调用示例。
- 恢复管理员可配置的独立生图站入口，前后端限制为无凭据的绝对 HTTP(S) URL；未配置或无效时显示安全空状态。
- 恢复 ModelPort 小铺空页面，仅复用余额充值和兑换码入口，不创建、不展示、不销售商品或订阅套餐。
- 保留即时抽奖和定时开奖，奖品支持余额与订阅兑换码，覆盖资格、次数、概率、库存、事务、幂等、审计及定时调度。
- 重构 `/home` 港口首页：真实港区照片叠加 Canvas 航道、数据船只和灯塔信标，响应鼠标、触控、滚动和窗口尺寸，并修复深色模式和减少动画降级。

## 数据库迁移

- `190_create_model_catalog_metadata.sql`：模型广场展示元数据和查询索引，价格仍由渠道配置提供。
- `191_create_lottery_system.sql`：抽奖活动、奖品、参与记录、开奖记录和事务事件表。
- `192_add_free_group_billing.sql`：分组免费计费标记。
- `193_add_channel_pricing_user_visibility.sql`：渠道模型价格的用户侧展示开关。
- 这些迁移均为增量变更，不删除现有字段或数据；190、191 已在真实 PostgreSQL 中验证重复执行，192、193 使用 `ADD COLUMN IF NOT EXISTS`。

## 验证结果

- 后端 Go 1.26.5 默认全量测试和 `unit` 标签全量测试通过。
- Testcontainers 真实 PostgreSQL/Redis 集成测试通过，覆盖迁移重复执行、模型身份唯一性、抽奖概率约束、并发库存、参与幂等和定时开奖只执行一次。
- 前端 211 个 Vitest 文件、1448 项测试通过；TypeScript、只读 ESLint 和生产构建通过。
- Playwright 在桌面、宽屏、平板和手机视口完成浅色、深色、减少动画截图；Canvas 非空、无横向溢出、首屏可见下一内容区。
- 已完成 Go 格式、Git 差异、路由权限、公开 URL、安全凭据、可见金额符号和平台中央颜色审计。

## 风险与兼容性

- 首次启动会自动确认迁移状态，耗时可能略高于普通重建；新增表和字段可由旧版本忽略。
- 定时抽奖每 30 秒检查到期活动，多实例依靠事务锁和唯一开奖记录防止重复派奖。
- 生图站跳转目标由管理员维护，错误地址会被拒绝或从公开设置中隐藏。
- 首页 Canvas 使用最高 2 倍设备像素比，并在 `prefers-reduced-motion` 下停止连续动画。
- 生产构建仍有既有的 Vite 动态导入和大分块警告，不影响运行。

## 更新与回滚

开发镜像：

```bash
docker pull ghcr.io/abingooo/modelport:0.1.164.8-dev.6
```

发布本身不会连接服务器或触发更新。管理员需要在测试站版本面板中选择开发版并人工确认。
更新前应保留 PostgreSQL、Redis 和 `/opt/modelport/.env` 备份。

如需回滚，将 `MODELPORT_IMAGE` 恢复为
`ghcr.io/abingooo/modelport:0.1.164.8-dev.5` 并仅重建应用容器；不要删除数据卷。
迁移 190-193 的表和字段可以保留，无需手工回退数据库。
