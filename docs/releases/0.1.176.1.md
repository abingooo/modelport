# ModelPort 0.1.176.1

> 本版本基于 Sub2API `v0.1.176`，合并上游正式更新并保留 ModelPort 的渠道定价、分组倍率和指令审核定制。

## 主要更新

- 支持分组逐模型定价和长上下文阶梯开关，实际计费优先级为“分组逐模型价 > 渠道价 > 内置价”。存在渠道价时，部分字段覆写会继续继承渠道价。
- 模型广场官方价仍取管理员配置的最早渠道原价；分组价与各类倍率只影响分组展示价和实收价。
- 支持 Grok 4.6、新订阅档位、X Search，并加强 Realtime 音频计费、Grok usage 完整性和响应模型计费防护。
- 加强 OpenAI Responses、Chat Completions、WebSocket、OAuth 和 Codex 指纹兼容。
- 定时备份增加多实例 leader 锁并改进大文件分卷备份；修复账号调度、运营指标与 API Key 输入校验。
- Go 工具链升级至 `1.26.6`，修复安全扫描识别出的标准库漏洞。

## ModelPort 定制保留

- 保留渠道定价 `user_visible`、国内 OpenAI-compatible provider、Composite、免费分组、利润控制及图片/视频/搜索/Voice 显式定价。
- 渠道和账号统计规则支持视频计费请求，并对嵌套定价执行后端校验；渠道与分组表单会拒绝非有限值和负数价格，同时保留显式零价格。
- 账号统计视频价按“分辨率档位每秒价优先、默认每秒价兜底”计算，并乘以完成视频数和归一化时长；缺失时长按 8 秒，显式零价有效。
- Composite 异步用量记录保留实际目标平台和强制平台上下文，账号统计与渠道定价不会跨平台误选价格。
- 保留首充 10% 与日常充值阶梯福利互斥，历史订单和重复回调不会重复发放。
- 保留指令审核 V2 的 AI 超时异步复审、客户端类型多选、筛选后全选删除、可信哈希原文及来源账号。
- 保留 DashScope 和 `qwen3.5-plus`、`qwen3.6-plus`、`qwen3.7-plus` 适配；WebSocket 同一 turn 只复用 `allow` 结果。
- 风控后端异常保持 fail-open；ModelPort 的 cyber policy 加密证据、通知和封禁计数配置继续生效。

## 数据库升级

- 不修改任何已发布 migration 的内容和 checksum。
- 新增 `223_group_model_pricing.sql`：为分组增加逐模型定价和长上下文开关，存量分组默认保持开启。
- 升级前必须备份 PostgreSQL；Grok Voice 归属仍依赖 Redis 持久化和备份。

## 发布

- 正式镜像：`ghcr.io/abingooo/modelport:custom-v0.1.176.1`，仅构建 `linux/amd64`。
- 发布流程只创建 GitHub Release 和 GHCR 镜像，不连接生产服务器；生产环境由管理员在 ModelPort 站内手动更新。
