# ModelPort 0.1.170.24

## 指令审核范围与日志

- 分组审核范围支持同时选择多个客户端类型，也兼容“全部客户端”与指定客户端共存。
- 审核日志支持筛选后全选或取消全选当前页，并可批量删除所选记录。
- 筛选、翻页和加载失败会清空旧选择；删除末页记录后会自动回退到有效页码。

## 可信哈希账号来源

- 可信哈希、风险哈希及异步复审任务会保存来源账号 ID 与邮箱快照。
- 来源事件或账号删除后仍保留邮箱快照；手工录入或仅导入摘要的记录会明确显示无账号来源。
- 新增迁移 `220_instruction_audit_v2_source_accounts.sql`，为历史记录回填仍可关联的账号来源。

## 阿里百炼兼容

- 指令审核 AI 节点可直接使用 `https://dashscope.aliyuncs.com/compatible-mode/v1`，不再重复拼接 `/v1`。
- 已覆盖 `qwen3.7-plus`、`qwen3.6-plus` 和 `qwen3.5-plus`，模型名会原样传递。
- 完整 `models` 或 `chat/completions` 端点可正确切换，同时保持普通代理目录的原有拼接行为。
