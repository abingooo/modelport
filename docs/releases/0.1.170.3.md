# ModelPort 0.1.170.3

## 账号管理修复

- 修复 DeepSeek、通义千问、智谱AI、Kimi、ByteDance、MiniMax 和小米 MiMo 账号创建统一返回 `400` 的问题。
- 创建、编辑、批量编辑和账号列表统一按照后端支持范围展示上游计费探测功能，国内平台不再提交不兼容的探测参数。
- 后端兼容旧页面缓存：不支持探测的 API Key 平台即使误传默认探测开关，也可正常创建账号且不会启用探测；OAuth 等非法账号类型仍保持严格校验。

## 验证与数据

- 七个国内平台均已通过测试服务器公网管理 API 的账号创建与删除回归，创建响应不会保留不兼容的探测标记。
- 针对性后端测试、前端组件测试、类型检查、变更文件 Lint 和生产构建均已通过。
- 本版本不新增数据库迁移，不修改已有账号、用户、余额、API Key、订阅、用量、模型定价、邀请或抽奖数据。

## 发布

- 正式镜像仅发布 `linux/amd64`，标签为 `ghcr.io/abingooo/modelport:custom-v0.1.170.3`。
- GitHub Actions 只创建正式 GitHub Release 和 GHCR 镜像，不自动更新测试服务器或生产服务器。
- 正式镜像继续先部署至测试服务器完成健康检查与版本回归，生产服务器保持人工更新。
