# ModelPort 0.1.166.2-dev.2

本开发版本包含 `0.1.166.2-dev.1` 的全部生产迁移护栏，并修正迁移目标断言在已运行测试库上
的误报。镜像仍只构建 `linux/amd64`。

## 迁移验证修正

- `usage_logs.billing_model` 以 `189_add_usage_log_billing_model.sql` 的实际应用时间为边界。
- 迁移前已有用量记录仍必须保持空值，防止迁移意外改写历史计费数据。
- 迁移后由 ModelPort 新产生的用量允许记录计费方式，使目标验证可在测试服重复执行。

## 继承能力

- 提供只连接 PostgreSQL 的 `/app/sub2api --migrate-only` 模式。
- 提供 PostgreSQL、Redis、TokensHub 周边触发器和首次启动外发围栏的审计与回滚工具。
- CLI 版本信息与首次安装提示显示 `ModelPort`，二进制路径保持兼容。
