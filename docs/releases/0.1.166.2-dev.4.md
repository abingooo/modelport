# ModelPort 0.1.166.2-dev.4

本开发版本补齐 TokensHub 核心业务切换后的部署品牌收口，镜像仍只构建 `linux/amd64`。

## 生产设置切换

- 新增可重复执行的 ModelPort 部署设置脚本，使用经验证的 HTTPS origin 更新公开 API 地址和
  充值回跳地址。
- 启用 ModelPort 内置站点名、Logo 和副标题，清空尚未适配的小铺、生图、旧模型广场和抽奖
  自定义菜单。
- 原设置、行 ID、更新时间和 `settings_id_seq` 完整保存在 cutover guard，流量切入前可精确
  恢复；用户、余额、API Key、定价、支付和订阅数据不参与修改。

## 验收基线

- 固定 AMD64 候选镜像完成 TokensHub 原始 dump 的 `236 -> 244` 迁移，二次执行幂等。
- 1494 个用户、1469 个 API Key、1,077,234 条用量及既有表归一化指纹保持不变。
- 9243 个 Redis 登录会话键在裁剪、AOF 开启和重启后保持数量、类型和内容指纹一致。
